# My app

**Domain:** Studying cafes in Seattle

**User story:** As a college student, I need to know which cafes in Seattle are good for studying, so that I'm able to pay attention, try yummy drinks, and stay there for a long period of time.

**What the user types or picks:** I want to have a way to look and visusally see how far each cafe is from me (given that I can add where I am). I want to have good seating, a busy chart to see if it's crowded at certain times or days, see if they have a drink or food menu, transportation methods to get there and its time. Always the vibe of each cafe (i.e. cute, studious, loud, dog-friendly, etc.) and if there's onsite bathroom and especailly if there's alot of available outlets and comfortable seating.
